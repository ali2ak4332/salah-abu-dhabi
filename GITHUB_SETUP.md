# GitHub-ready Salah project

This archive is prepared for GitHub. The Android signing key has intentionally been excluded.

## Initial repository setup

Create a repository named `salah-abu-dhabi` in your GitHub account and upload this source tree (or connect a development agent with repo creation permission). Public source is optional; public repositories must never include signing certificates, keystores, passwords, or other credentials.

On each push / pull request, `.github/workflows/android-check.yml` builds a **debug APK** and runs the existing pure-Java logic tests. Android app launches, widgets, alarms and real device notifications still need device verification. A successful build does not imply those behaviors were tested.

## Keeping installs upgrade-compatible

The original source archive included a personal-test signing key. It is not included here. Debug APKs generated by GitHub Actions will use a different local debug key and cannot necessarily be installed as updates over the current app. Keep your signing ZIP locally and securely. Do not upload it to GitHub, even if the code repository is public.

## Existing features

The current source is version 1.6. The requested day/date at the top of both widgets remains a pending code change. Estimated iqama timing is already implemented in `PrayerPhase` and the provided tests cover exact boundaries, though a physical device has not been checked in this preparation.
